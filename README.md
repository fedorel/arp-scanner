# Network ARP Scanner

Консольный инструмент для сканирования локальной сети с использованием ARP-запросов. Программа определяет IP и MAC-адреса всех активных устройств в указанной подсети и выводит результат в виде таблицы.

## Требования и зависимости

Проект написан на языке Python 3. Для его работы необходимы следующие внешние библиотеки:
* Scapy — для сборки, отправки и перехвата сетевых пакетов.
* Tabulate — для форматирования и отображения табличных данных.

### Примечание для пользователей Windows
Для корректной работы сетевой карты в неразборчивом режиме (Promiscuous Mode), который необходим для перехвата ARP-ответов, в системе должен быть установлен драйвер Npcap.
Установщик доступен на официальном сайте: https://npcap.com/
